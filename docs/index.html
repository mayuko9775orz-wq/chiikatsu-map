    Googleマップ連携
    Googleマップへの取り込み方
    1. 上のボタンで、いま一覧に出ているスポットをファイル（CSV）に保存します。
    2. パソコンで Googleマイマップ を開き、「新しい地図を作成」→「インポート」で保存したファイルを選びます。
    3. 目印の位置には「緯度」と「経度」、タイトルには「名前」を選びます。「スタイル」で「種類」を選ぶと、色分けできます。
    4. スマホの Googleマップ アプリでは「保存済み」→「マイマップ」から見られます。

    このサイトについて

    「ちいかわ」が好きな個人がつくった非公式のまとめです。原作者・公式・各店舗とは関係ありません。キャラクターの画像やロゴは使わず、店名・場所・期間などの情報と、公式ページへのリンクだけを載せています。

    情報は 2026年10月14日 時点で集めたものです。営業時間、整理券や予約、入店制限、イベントの期間は変わりやすいので、各スポットの「情報元」で最新の案内を確認してください。店内でのグッズ交換や転売目的の購入は、多くの店舗で禁止されています。
